# 岁岁念 · 使用说明

> 岁岁常欢愉，年年皆胜意。

这个插件帮你记住朋友的生日：到了日子，猫娘会在**当天第一次主动搭话**时自然地把生日说出来；如果你还没确认，她会隔一段时间再提醒，直到你说已经祝福过，或者让她今天别再提醒。

## 1. 先让插件跑起来

1. 在 N.E.K.O. 的插件页刷新列表，找到「生日提醒」并启动。
2. 打开插件详情里的「自动启动」开关。否则应用重启后插件不会自己运行，提醒也不会发生。
3. 打开「生日提醒」面板，可以直接添加朋友，也可以导入表格。

> 提醒依赖猫娘主动搭话。如果全局主动搭话被关掉了，插件仍会在设定时间发一条主动消息让猫娘开口；但如果你希望它更自然地混进日常主动搭话里，请保留主动搭话功能。

## 2. 直接编辑

在面板里点「添加朋友」，填写：

- **姓名**：必填，例如「小林」。
- **生日**：必填。支持 `1995-08-12`、`08-12`、`1995/8/12`、`1995年8月12日`。不写年份就按每年同一天提醒（目前按公历）。
- **备注**：选填，例如「喜欢咖啡，别送太贵的礼物」。
- **标记**：`提前提醒送礼`、`特别关心`，可以同时选。

标记的作用：

- **提前提醒送礼**：在生日前 N 天（默认 7 天，可改）提醒你准备礼物；生日当天也会提醒别忘了礼物。
- **特别关心**：目前用于提高提醒消息的优先级、在名单里置顶，并让猫娘在措辞上更认真一点。以后可以继续扩展用途。

## 3. 从 xlsx 导入

把表格拖进面板的「从表格导入」，或者点「选择文件」。第一行表头需要是：

```text
姓名        生日         备注                 标记
小林        1995-08-12   喜欢咖啡             提前提醒送礼
阿澄        08-12        大学同学             特别关心
小夏        2000/2/29
```

说明：

- 支持 `.xlsx`、`.xlsm`、`.csv`；旧版 `.xls` 请先在 Excel 里另存为 `.xlsx`。
- 列顺序可以换，只要表头名字能对上；`姓名/名字/name`、`生日/出生日期/birthday`、`备注/说明/note`、`标记/标签/tags` 都能识别。
- 同姓名 + 同月日的记录会更新，其他会新增。
- 标记列可以写「提前提醒送礼」「特别关心」，多个用逗号、顿号或空格分隔。
- 日期既可以是文本，也可以是 Excel 的日期单元格；导入结果会显示新增、更新和出错的行号。

## 4. 提醒是怎么发生的

默认设置：

- 每天 `08:30` 开始提醒，`22:30` 之后不再提醒；
- 没确认时每 `60` 分钟再提醒一次，每天最多 `3` 次；
- 每天 `00:05` 之后，如果今天有人生日，插件会先把生日信息作为**上下文**交给猫娘（不单独发消息）。这样她在当天第一次主动搭话时，可以自然地提起生日；
- 到了 `08:30` 你还没确认，插件会发一条主动提醒，让猫娘开口对你说。之后按间隔重复，直到你确认或说「今天别提醒了」。

为什么要有「上下文」和「主动提醒」两层：插件不能修改宿主已经生成好的主动消息，所以先在上下文里放一份生日备忘，让猫娘在第一次主动搭话时有机会自然提起；如果她没有提，或者当天她没有主动搭话，插件再补一条明确提醒。你可以在设置里关掉「先把生日写进上下文」。

## 5. 怎么确认「已经祝福」

任选一种：

1. **直接对猫娘说**：「我已经发过祝福了」「刚给她发了消息」「打过电话了」「好了，今天别提醒了」。猫娘会调用 `birthday_ack` 工具登记；模糊或等价的说明也算。
2. **在面板点**「标记已祝福」；如果今天有多个朋友，会分别标记。
3. **点**「今天别再提醒」，当天不再发送任何生日/送礼提醒（不要求已经祝福）。

插件也会从最近的对话里识别常见说法（例如「已经发了」「别提醒了」）作为兜底。识别只在当天有提醒、且句子出现在最近提醒之后时生效，避免把旧对话误当成确认。

想先看看猫娘会怎么说，可以点「测试提醒」：它会立即发一条预览，不消耗当天的提醒次数，也不会改变确认状态。

## 6. 设置

面板底部可以改：

- 每天开始提醒的时间、停止提醒的时间；
- 重复间隔、每天最多提醒次数；
- 提前送礼提醒天数（0 = 关闭）；
- 时区（默认 `Asia/Shanghai`）；
- 是否使用「上下文」提醒、是否从对话里识别确认。

设置保存在插件数据目录，不会覆盖你的名单。

## 7. 数据与隐私

- 名单、当天确认状态、设置都保存在 `<用户数据目录>/plugins/birthday_reminder/data/birthdays.json`。
- 插件只读取最近的对话轮次来做「已经祝福」的兜底识别，不保存对话原文；识别结果只写「某人已祝福」和一条最长 80 字的备注。
- 生日信息会通过插件消息进入猫娘的上下文；如果你使用云端模型，这部分内容会按 N.E.K.O. 正常的对话链路发送给模型提供方。

## 8. 常见问题

**今天没有提醒？**

1. 插件是否在运行、是否打开了「自动启动」；
2. 当前时间是否在「开始提醒」和「停止提醒」之间；
3. 是否已经点过「今天别再提醒」，或已经达到当天最大提醒次数；
4. 名单里的生日是否是今天（2 月 29 日在非闰年按 2 月 28 日提醒）；
5. 打开「调试状态」入口，查看 `day_state`、`today`、`prep_due` 是否符合预期。

**提醒重复太频繁？**

把「重复间隔」调大，或把「每天最多提醒次数」调小。

**为什么猫娘说的和备注不完全一样？**

插件给的是事实和意图，具体措辞由猫娘按当前人格生成；她可能会用自己的方式表达。
